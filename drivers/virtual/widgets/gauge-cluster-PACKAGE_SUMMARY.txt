DRIVER CLASS API (rf_bench.virtual.VirtualGaugeCluster)
--------------------------------------------------------

Connection:
  __init__(host, port=5025, timeout=2.0)
  close()
  Context manager support (with statement)

IEEE 488.2 Commands:
  idn() → str
  reset()
  get_error() → str

Layout Management:
  set_layout(count)  # 2 or 4 gauges
  get_layout() → int

Gauge Value Control (1-based indexing: 1-4):
  set_value(index, value)
  get_value(index) → float
  update(index, value)  # alias for set_value
  update_all(values)    # dict or list

Gauge Configuration (1-based indexing: 1-4):
  set_min(index, min_val)
  get_min(index) → float
  set_max(index, max_val)
  get_max(index) → float
  set_units(index, units)
  get_units(index) → str
  set_label(index, label)
  get_label(index) → str
  set_color(index, color)
  get_color(index) → str

MQTT Integration:
  configure_mqtt(index, host, topic)
  get_mqtt_config() → str

Convenience Methods:
  configure_gauge(index, label, units, min_val, max_val, color="#00ff00")
  animate(index, values, interval=0.1)

USE CASES (from README.md)
---------------------------

1. Power Supply Monitoring (SPD3303X)
   - 4-gauge dashboard: V, I, P, Load%
   - Real-time measurement display

2. Radio Dashboard (IC-7300)
   - S-meter, TX power, SWR, ALC
   - Multi-parameter radio monitoring

3. TX Forward/Reflected Power Monitor
   - 2-gauge layout
   - Forward/reflected power tracking

4. Environmental Sensors (MQTT)
   - Temperature, humidity, pressure, AQI
   - MQTT auto-update from sensors

5. Battery Discharge Monitor
   - Voltage, current, capacity (Ah), SOC (%)
   - Real-time discharge tracking

6. Multi-Channel Spectrum Monitor (RTL-SDR)
   - 4 bands: 2m, 70cm, APRS, ISM
   - Real-time RF power levels

7. Antenna Rotator Status
   - Azimuth and elevation display
   - ESP32 SCPI rotator controller


BACKEND SERVER REQUIREMENTS
----------------------------

Location: ~/Dropbox/build/rf-bench/virtual/gauge-cluster/backend/server.py

Start server:
  cd ~/Dropbox/build/rf-bench/virtual/gauge-cluster/backend
  python3 server.py

Default ports (as checked on 2026-06-14):
  - SCPI TCP: 5009 (line 230 in server.py)
  - HTTP/WebSocket: 8009 (line 456 in server.py)

Note: For production use, edit server.py to use standard ports:
  - SCPI: 5025 (industry standard)
  - HTTP: 8010

Dependencies (backend):
  pip install fastapi uvicorn websockets paho-mqtt --break-system-packages

DIFFERENCES FROM ANALOG-METER
------------------------------

1. Layout: 2 or 4 gauges (not 1-4 with ROW/COL/2X2)
2. MQTT: Per-gauge MQTT config (not global)
3. Additional method: update_all() for batch updates
4. Backend: Different SCPI port (5009 vs 5025)
5. Use case: Dashboard monitoring (not single-meter display)
