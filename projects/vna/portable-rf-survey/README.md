# portable-rf-survey — Batch many DUT sweeps, HTML index

For an installation visit: capture VSWR for every patch lead /
antenna / feedline in the rack, get a single HTML index linking
to all PDFs.

## Config file

JSON:

```json
{
  "start_mhz": 1.0,
  "stop_mhz":  500.0,
  "duts": [
    {"label": "100 ft RG-58 attic feed"},
    {"label": "20 ft RG-58 patch"},
    {"label": "PL-259 jumper #3"},
    {"label": "diplexer common port"}
  ]
}
```

## Usage

```bash
python portable_rf_survey.py --config survey.json --out-dir ~/site_2026_06/
```

The script prompts you between DUTs:

```
DUT 1/4: connect '100 ft RG-58 attic feed', press Enter…
```

## Output

- One PDF per DUT (via swr-pdf)
- One HTML index linking to all PDFs

## Flags

- `--config FILE.json` — required
- `--out-dir DIR`
- `--vna`, `--port`, `--host`
- `--no-prompt` — skip the manual confirmation prompts (relay-driven swap)

## Notes

- Each PDF is generated by `../swr-pdf/` so all the swr-pdf options
  (band shading, etc.) apply.
- Site-visit workflow: load the config on a laptop, walk the rack
  with the VNA, hit Enter after each connection. ~30 s per DUT
  including connect/disconnect time.
